# FinLedger

Локальная система учёта на Next.js, Prisma и PostgreSQL в Docker. Она использует тарифы 7%, 12%, 17% и SIM-лимиты 15 000 ₽ из исходной таблицы.

## Быстрый запуск

```powershell
npm install
npm run db:up
npm run db:setup
npm run dev
```

Откройте http://localhost:3000. Приложение локальное, без входа по паролю.

Для повседневной работы (без пересборки): `npm run db:up`, затем `npm run dev`. Для запуска собранной версии: `npm run build`, затем `npm start`. Не запускайте `npm run dev` и `npm start` одновременно в этой папке — они используют одну папку `.next`, и работающий сервер перестанет отдавать свои файлы (белый экран).

## Тарифы и курсы

Страница «Тарифы и курсы» редактирует значения по умолчанию для новых операций. В «Операциях» тариф, курс полученной валюты и курс отправленной валюты всегда изменяются вручную для конкретной операции. После сохранения значения остаются привязанными к этой операции и не меняются вслед за справочником.

## Команды

- `npm run db:up` — запустить PostgreSQL в Docker;
- `npm run db:setup` — применить миграции и загрузить данные;
- `npm run test` — unit-тесты формул;
- `npm run lint` — проверка кода;
- `npm run build` — production-сборка;
- `npm run bot` — Telegram-адаптер (при пустом токене завершится безопасно).

`start-local.ps1` выполняет полный локальный запуск. `backup.ps1` сохраняет до десяти SQL-копий в `backups`; `restore.ps1 -BackupFile backups/имя.sql` сначала сохраняет текущее состояние, затем восстанавливает выбранную копию.
